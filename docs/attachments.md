# Вложения в noda

Скрепка слева от ввода доступна в личной переписке и текстовом канале при наличии права отправки.

- Один файл на сообщение, от 1 байта до 10 МБ, с подписью или без неё.
- До отправки видны имя, размер и миниатюра поддерживаемого изображения. Крестик убирает вложение.
- Вложение привязано к переписке: переключение экрана не меняет адресата загрузки.
- Во время отправки показан процент. При ошибке файл остаётся для повторной попытки.
- Изображения PNG, JPEG, WebP, GIF и BMP отображаются в переписке; нажатие открывает крупный просмотр внутри окна. GIF показывается первым кадром. «Сохранить» в просмотре или «Скачать файл» в меню открывает выбор места сохранения. Нажатие на обычный файл также открывает сохранение. Скачивание показывает процент и поддерживает отмену. Файлы автоматически не открываются.

## Хранение и протокол

Миграция chat attachments сохраняет старые сообщения и добавляет метаданные, блоки содержимого и ссылки из сообщений. Используется SQLite-база чата; сервер не создаёт файлов по присланным путям.

begin_attachment, upload_attachment_chunk, download_attachment_chunk используют существующий защищённый транспорт. Блок — 48 КиБ. Максимум зарезервированного хранения на отправителя — 100 МиБ. Незавершённые загрузки старше суток удаляются при начале следующей загрузки вместе с блоками.

Проверяются сессия, автор, адресат/канал, право писать, последовательность и размеры блоков, SHA-256. Повтор блока допустим только при совпадении содержимого. Получателю доступны только вложения опубликованных сообщений. Для каналов при скачивании проверяются актуальное членство и существование текстовой комнаты.

Клиент выполняет файловые и сетевые операции в фоновом потоке. Скачивание идёт во временный файл рядом с назначением; замена назначения происходит после проверки размера и SHA-256. Ошибка или отмена удаляет временный файл. История содержит только метаданные.

Требуется обновление клиента и сервера. Текущие ограничения: один файл за отправку, GIF показывается первым кадром. Для просмотра изображения ограничены 40 миллионами пикселей и декодируются до 2048 пикселей по длинной стороне; сохранение файла оставляет оригинал.

Предпросмотр загружает данные в фоне через тот же авторизованный протокол, проверяет SHA-256 и формат содержимого. Картинки хранятся только в памяти (64 МиБ на переписочную панель), не сохраняются в пользовательские папки. Одновременно выполняется до двух загрузок. Размер места под картинку не меняется после загрузки, поэтому она не сдвигает историю.

## Вставка и перетаскивание

Ctrl+V в Windows и Cmd+V в macOS вставляют изображение из буфера как выбранное вложение, сохраняя введённую подпись. Файл также можно перетащить на историю, пустую переписку или поле ввода. Автоматической отправки нет. Сохраняется ограничение: один файл на сообщение, до 10 МБ; при переносе нескольких файлов показано пояснение без замены текущего вложения. Временные PNG из буфера удаляются при снятии вложения, успешной отправке или сбросе сессии. Исходные файлы пользователя не удаляются.

Веб-ссылки http/https и www подсвечиваются и открываются в системном браузере по нажатию. Декоративный текст вложений не превращается в ссылку. Системные/file/javascript-схемы не запускаются.
