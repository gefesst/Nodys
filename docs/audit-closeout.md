# Итоги исправлений аудита — 28 октября 2026

## Исправлено в коде

- Запуск клиента/сервера, импорты и вспомогательные методы после рефакторинга; проверки импорта, схем и Qt-сценариев находятся в `tests`.
- Авторизация TCP/UDP: личность из сессии, права отправителя и получателей, отзыв доступа после исключения/выхода/смены политики, защищённые голосовые разрешения.
- Изменение пароля требует текущего пароля; другие сессии и голосовые разрешения отзываются. Отложенный выход привязан к исходному токену.
- Звонки и события сохраняются транзакционно; независимые heartbeat участников, восстановление снимка состояния и защита нового звонка от старой команды закрытия.
- Повторная доставка поддерживаемых изменений не создаёт повторные сообщения/каналы/приглашения. Ошибка операции откатывает изменения; повторный ID с другим содержимым отклоняется.
- Каналы выделены в сервис. Удаление истории между двумя БД использует сохраняемую очередь очистки вместо молчаливого игнорирования ошибки.
- Миграции с резервной копией, проверкой версии и откатом. Пользовательские данные сохраняются при обновлении.
- Выход при недоступном сервере сохраняется в локальную очередь и повторяется при запуске/по таймеру. Конфигурация записывается атомарно с приватными правами.
- Голос: шифрование, replay-защита, обновление ключей, восстановление после перезапуска relay, смешивание говорящих, порядок медиапакетов и сглаживание коротких потерь. Соединение SQLite повторно используется без кеширования разрешений.
- UI: асинхронное восстановление сессии и голосовое подключение, защита от устаревших ответов, сохранение форм/настроек при опросе, прокрутка настроек, переносимые аватары, корректное присутствие.
- Функционал «Компактно» удалён из страниц друзей, чатов, каналов и таблицы стилей. Адаптация размеров окна сохранена.
- Зависимости зафиксированы. Один TLS-просмотр для разработки; сборка приложения отложена.

- 121 тест `unittest` (без пропусков): успешно. Включают реальные локальные TLS/UDP-соединения с искусственным PCM, права/отзыв разрешений, конкурирующие запросы, миграции/откат, идемпотентность, очередь выхода, Qt lifecycle и jitter-buffer.
- `compileall` и `git diff --check`: успешно.
- `pip check`: конфликтов установленных зависимостей нет.
- `pip-audit 2.10.1` по зафиксированным зависимостям: известных уязвимостей не найдено на момент проверки. Это не гарантия отсутствия неизвестных уязвимостей.
- `tools/preview.py --tls --smoke-seconds 8`: оба клиента и оба сервера выдержали процессный smoke-тест. Это не проверка качества микрофона.
- Поиск `compact`/`компакт` в `client`: совпадений нет.

## Что нельзя считать закрытым автоматическими тестами

1. Два физических компьютера и разные сети: NAT, переключение Wi-Fi, сон/пробуждение и длительные обрывы.
2. Реальный групповой звук: разные микрофоны/наушники, задержка, эхо, длительный разговор и смена устройства. Ранее пользователь подтвердил звук между двумя аккаунтами, но новую версию медиабуфера нужно прослушать заново.
3. Длительная нагрузка на выбранном сервере и независимая проверка безопасности собственного голосового протокола перед публичным запуском.
4. Финальная упаковка, подпись, обновление и испытания установленного приложения — намеренно отложены пользователем.

Это внешние критерии приёмки перед выпуском, а не незаконченные исправления кода. Разделение серверных обработчиков и клиентских контроллеров выполнено в заключительном проходе: сервисы аккаунтов/дружбы/событий, хранилище сообщений, адаптер запросов, контроллер звонков и политика опроса. Крупные медиа и адаптивный кодек — новые возможности за пределами текущего набора функций.

## Ручной просмотр

Запустить `Просмотр Nodys.command`. Проверить вкладки и изменение размеров без переключателя «Компактно»; открыть настройки канала и прокрутить; изменить аватар; отправить сообщение; войти/выйти из голосового канала; позвонить Alice → Bob и завершить; повторить звонок. Для смены пароля нужен текущий тестовый пароль `preview-only`. Данные просмотра временные. Клиент и сервер обновляются одновременно: голосовой протокол теперь NV2.

## Заключительный проход

- Основная платформа — Windows; добавлен `.cmd` launcher и его запуск в CI. macOS поддерживается тем же клиентом. Локальный Windows-компьютер для этих автоматизированных проверок не нужен.
- Ошибки отзыва сессии больше не скрываются. Проверка пароля и выдача токена атомарны относительно смены пароля; Unicode legacy-пароли корректно обновляются.
- Запоздавшие accept/decline/end привязаны к ID звонка. Контроллер отбрасывает ответы старой сессии и снимки, полученные до изменения состояния.
- Убрана повторяющаяся логика завершения фоновых задач из главного окна; навигация, закрытие и повторный вход проверены Qt-тестом.
- Добавлены лимиты UDP до обращения к БД, ограниченные кеши, абсолютный срок чтения ответов, тесты повреждения каждого байта зашифрованного пакета, конкурентных nonce, границ пакетов, истечения разрешения и изоляции комнат.
- Ruff: неопределённых имён нет. Bandit: замечаний средней/высокой критичности нет. Проверка зависимостей: известных уязвимостей нет на дату запуска. Дополнительная ручная ревизия описана в `security-review.md`; она не выдается за независимую сертификацию.
- GitHub CI теперь запускает полный набор без допустимых пропусков, импорт/компиляцию, TLS preview и проверки безопасности. Результаты конкретной ревизии доступны во вкладке Actions.

Исправления кода из текущего аудита и согласованное разделение ответственности завершены. Выпуск приложения, испытания оборудования/внешних сетей и независимая оценка протокола не объявляются выполненными.

Полный process smoke в CI дополнительно выявил падение Qt при доставке сетевых результатов на Windows/Linux. `NetworkThread` теперь удерживается до завершения рабочего потока и доставки результата, а публичные callbacks вызываются через явный queued-slot в GUI-потоке; отмена проверяется повторно перед доставкой. Добавлены проверки потока выполнения и отмены уже поставленного в очередь ответа.
